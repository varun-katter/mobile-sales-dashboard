# 📱 Mobile Sales Performance Dashboard

## 📌 Project Description
Developed an interactive Power BI dashboard to analyze mobile sales performance across multiple cities, brands, and payment methods. The dashboard provides actionable business insights through dynamic visualizations, KPI tracking, and trend analysis.

## 🔍 Key Features
- Sales & Revenue Analysis
- Brand Performance Tracking
- Customer Rating Insights
- Payment Method Analysis
- City-wise Sales Distribution
- Interactive Filters & Slicers

## 🛠 Tech Stack
- Power BI
- DAX
- Excel
- Power Query

## 📈 Key Business Insights
- Apple and Samsung contributed major revenue share
- UPI and Debit Card were the most preferred payment methods
- Major metropolitan cities generated higher sales volume
- Customer ratings helped identify top-performing products
